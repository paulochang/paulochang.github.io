# JSON Query Tool (JSONata)

Three panels: paste JSON on the left, browse it as a tree in the middle, where clicking a value copies its path, and write a JSONata query on the right. Results update as you type, and there's autocomplete and a list of sample queries. Built on Monaco Editor and JSONata.

The tool runs in the browser, so this file only describes it. Use it at https://paulochang.com/json/.
