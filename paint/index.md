# Geometric Wall Designer

Generates wall patterns you can paint with masking tape, so straight lines only and at most three colors. Sliders set the grid size and complexity, there's a "snap to larger blocks" option, and you can export the result as a PNG. The two earlier versions are still online: [v1](https://paulochang.com/paint/v1.html) and [v2](https://paulochang.com/paint/v2.html).

The designer runs in the browser, so this file only describes it. Use it at https://paulochang.com/paint/.
